🧮 BMI Calculator (React)

A simple Body Mass Index (BMI) Calculator built with React.js.
It allows users to calculate their BMI based on height and weight, and provides feedback on their health category.

🚀 Features

Input fields for Height (cm) and Weight (kg)

Calculates BMI value instantly

Displays BMI category (Underweight, Normal, Overweight, Obese)

Responsive UI with clean design

Built using React Hooks (useState, useEffect)

🛠️ Tech Stack

React.js

JavaScript (ES6+)

HTML5 & CSS3

📦 Installation

Clone the repository

git clone https://github.com/your-username/bmi-calculator.git


Navigate to the project folder

cd bmi-calculator


Install dependencies

npm install


Run the project

npm start


Open in browser

http://localhost:3000

BMI Range	Category
Below 18.5	Underweight
18.5 – 24.9	Normal Weight
25 – 29.9	Overweight
